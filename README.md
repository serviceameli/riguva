Публичный прототип для просмотра и согласования с автором.

- Два мира, книги, артефакты, материалы и страница об авторе.

- Это статическая сборка для GitHub Pages. Подключение Тильды и эквайринга выполняется отдельно.

Исходные изображения и анимации сохранены. Сборка содержит только используемые сайтом файлы и материалы для скачивания.
